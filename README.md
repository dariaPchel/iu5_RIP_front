# POSPOM — фронтенд (лабораторная работа 5)

Базовое SPA на React + TypeScript для просмотра факторов риска послеоперационных осложнений по шкале POSPOM. Данные берутся из коллекции `mock` (`src/modules/mock.ts`), бэкенд не подключён.

## Стек
React, TypeScript, Vite, React Router, React-Bootstrap. Redux и Context не используются.

## Запуск
```bash
npm install
npm run dev
```

## Структура
```
public/            default-photo.png, default_video.mp4 (изображение и видео по умолчанию)
src/assets/        иконки навигации, логотип, картинки карточек
src/modules/       mock.ts — коллекция mock-объектов
src/components/    Header, BottomNav, Layout, AgeFilter, RiskCard
src/pages/         FeedPage, GridPage, AddPage, LoginPage
```

## Страницы

### Лента — `/risk_factors_feed/:id`
Фоновое видео карточки (если видео не задано — `default_video.mp4`, при ошибке загрузки — картинка), название, подзаголовок «Фактор риска», количество лайков, описание, возраст и ИМТ.
- **ещё / скрыть** — разворачивает и сворачивает полное описание.
- **Стрелка вверх** — предыдущая карточка.
- **Стрелка вниз** — следующая карточка.

### Плитка — `/risk_factors_grid`
Карточки в две колонки: изображение (если не задано — `default-photo.png`), название, количество лайков.
- **Ползунок «Фильтр по возрасту пациентов»** (0–100, по умолчанию 50) — выбор максимального возраста.
- **Применить** — оставляет карточки с возрастом не больше выбранного.
- **Клик по карточке** — открывает её в ленте.

### Добавить — `/risk_factors_add` (недоступна из navbar)
Двухшаговая форма.
- Шаг 1: поле **«Название фактора риска»**, кнопка **«Далее (Сохранить черновик)»**.
- Шаг 2: поля **«Описание»**, **«Возраст (лет)»**, **«ИМТ»**, отметка «Черновик» с датой создания, кнопка **«Опубликовать карточку»**.

### Вход — `/login` (недоступна из navbar)
Заглушка: авторизация будет реализована в следующей лабораторной работе.
